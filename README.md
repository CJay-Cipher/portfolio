This repository previously hosted my **Frontend Developer Portfolio** on GitHub Pages. The live project has been migrated to a new hosting platform for better performance and deployment workflows.

## 🚀 New Location

The portfolio is now permanently hosted on **Vercel**.

👉 **Live Site:** [cjay-portfolio.vercel.app](https://vercel.app)

This repository now functions strictly as a **redirect gateway**. The `index.html` file uses an immediate meta-refresh and a JavaScript fallback to instantly route any old traffic or legacy links directly to the new Vercel deployment.
